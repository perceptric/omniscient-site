# Blog price sheet (checked November 20 to 23, 2026)

Every list post takes prices from here. Each line was read on the vendor's own pricing page this month. Write prices in the listicle format: `Tier: $X/user/month billed annually or $Y/user/month billed monthly`. Where a page gives one figure with no billing label, write the figure with no billing term. Where we couldn't read a price, link "See pricing" to the vendor's page and log it in docs/blog-checks.md.

Ratings: only the Capterra scores already in our posts (listed under each tool). G2 blocks our reader, so no G2 scores. Never add a score that isn't listed here.
