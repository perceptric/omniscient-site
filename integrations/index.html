Questions4.0

Questions, answered

Still curious? Book a demo and we'll walk you through it.

Do I need an API key to connect a tool?

No. Each tool connects with its own sign-in. API keys are only for developers, under Settings > Apps > Developers.

Can I import from my old CRM?

Yes. HubSpot, Salesforce, Attio and Pipedrive import in a few clicks, and CSV works for anything else.

Does Omniscient post to LinkedIn?

Never. The Chrome extension only saves the profile you are looking at when you click.

Can I disconnect an app?

Yes. Disconnect any app in Settings > Apps, and syncing stops right away.
