Questions4.0

Questions, answered

Still curious? Book a demo and we'll walk you through it.

What is MCP?

The Model Context Protocol lets assistants like Claude and ChatGPT use outside tools. Omniscient's MCP server lets them read and update your CRM.

Which clients work?

Claude, ChatGPT, Cursor and any MCP client that supports remote servers.

How does sign-in work?

Your client opens the approve page, you sign in to Omniscient and approve. You can also use an API key from Settings > Apps > Developers.

Can I limit what an assistant can do?

Yes. API keys can be read-only or read and write, and you can revoke any key or connection at any time.
